## Importar proyectos

Permite cargar muchos proyectos de una sola vez desde un archivo Excel
(.xlsx) o CSV, en 5 pasos.

### 1-2. Tipo y plantilla

Elegí el tipo de proyecto y descargá su plantilla — tiene las columnas
exactas que la app espera. Completá una fila por proyecto; la columna
**Nombre** es obligatoria.

### 3. Subir archivo

Subí el mismo archivo de la plantilla, ya completado.

### 4. Vista previa

Antes de confirmar la importación, la app te muestra una vista previa de
las filas detectadas: cuáles están listas para crear y cuáles tienen
errores (por ejemplo, un dato inválido o un "Nombre" vacío), para que
corrijas el archivo si hace falta antes de crear nada.

### 5. Confirmar

Al confirmar, se crean los proyectos de las filas válidas. Las filas con
error se muestran al final para que las corrijas y las vuelvas a subir
en un archivo aparte si querés.
