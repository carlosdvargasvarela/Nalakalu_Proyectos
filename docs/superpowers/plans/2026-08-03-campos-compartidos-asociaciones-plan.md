# Campos compartidos entre proyectos asociados Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an admin mark, per `ProjectTypeAssociation`, which `custom_fields` keys are "shared" between the two project types, so that quick-creating an associated project prefills those fields from the source project.

**Architecture:** A new `shared_field_keys` jsonb column on `ProjectTypeAssociation` stores the admin's chosen keys. The admin form gets a JS-driven checklist (plain vanilla JS, no Stimulus/importmap — matches this codebase's existing pattern in `projects/show.html.erb`) that recomputes which keys are "compatible" (same `key`, same `data_type`, same `reference_table` if `data_type == "reference"`) whenever the from/to type selects change. `ProjectsController#new` uses the stored `shared_field_keys`, re-filtered for compatibility at request time, to prefill `@project.custom_fields` from the source project before rendering the quick-create form.

**Tech Stack:** Ruby on Rails 7.2, PostgreSQL, Minitest (fixtures, `ActiveSupport::TestCase`, `ActionDispatch::IntegrationTest`), vanilla JS (no build step — inline `<script>` tags, same as the rest of the app).

## Global Constraints

- This only affects the quick-create flow (`ProjectsController#new`/`#create` with `associate_with_project_id` + `project_type_association_id`). Linking to an already-existing project gets no prefill and no validation.
- No sync after creation: editing the copied field, or changing the source project later, never re-syncs anything.
- `shared_field_keys` is not referentially validated against `field_definitions` — stale keys (field deleted after being marked shared) are silently ignored at read time, both in the admin checklist and in the prefill logic.
- Only copy a field when the source project's value for that key is present (not `nil`/blank).
- No new JS framework/dependency — inline `<script>`, `document.addEventListener`, matching `app/views/projects/show.html.erb`'s existing `filterProjects` pattern.

```ruby
class Admin::ProjectTypeAssociationsController < Admin::BaseController
  before_action :set_project_type_association, only: [:edit, :update, :destroy]
  before_action :set_field_definitions_by_type, only: [:new, :create, :edit, :update]

  def index
    @project_type_associations = ProjectTypeAssociation.all
  end

  def new
    @project_type_association = ProjectTypeAssociation.new
  end

  def create
    @project_type_association = ProjectTypeAssociation.new(project_type_association_params)
    if @project_type_association.save
      redirect_to admin_project_type_associations_path
    else
      render :new, status: :unprocessable_entity
    end
  end

  def edit
  end

  def update
    if @project_type_association.update(project_type_association_params)
      redirect_to admin_project_type_associations_path
    else
      render :edit, status: :unprocessable_entity
    end
  end

  def destroy
    @project_type_association.destroy
    redirect_to admin_project_type_associations_path
  end

  private

  def set_project_type_association
    @project_type_association = ProjectTypeAssociation.find(params[:id])
  end

  def set_field_definitions_by_type
    @field_definitions_by_type = ProjectType.includes(:field_definitions).each_with_object({}) do |project_type, hash|
      hash[project_type.id] = project_type.field_definitions.map do |field|
        { key: field.key, label: field.label, data_type: field.data_type, reference_table: field.reference_table }
      end
    end
  end

  def project_type_association_params
    params.require(:project_type_association).permit(
      :from_project_type_id, :to_project_type_id, :label, :responsables_can_create,
      shared_field_keys: []
    )
  end
end
```

(The `hidden_field_tag` with an empty value is the standard Rails trick so that submitting the form with every checkbox unchecked still sends `shared_field_keys: [""]`, which Rails/ActiveRecord's array-typecasting turns into `[]` rather than leaving the param absent and the attribute untouched.)

- [ ] **Step 2: Add the reactive JS**

Right before the closing `<% end %>` of `_form.html.erb` (after `form.submit`/cancel link if any — this form has no cancel link, so just after `form.submit`), add:

```erb
    <script>
      document.addEventListener("DOMContentLoaded", function () {
        var fromSelect = document.querySelector("#project_type_association_from_project_type_id");
        var toSelect = document.querySelector("#project_type_association_to_project_type_id");
        var container = document.getElementById("shared-field-keys-checks");
        var dataEl = document.getElementById("field-definitions-by-type");
        if (!fromSelect || !toSelect || !container || !dataEl) return;

        var fieldsByType = JSON.parse(dataEl.textContent);
        var initiallyChecked = <%== (project_type_association.shared_field_keys || []).to_json %>;

        function compatibleFields() {
          var fromFields = fieldsByType[fromSelect.value] || [];
          var toFields = fieldsByType[toSelect.value] || [];
          var toByKey = {};
          toFields.forEach(function (f) { toByKey[f.key] = f; });

          return fromFields.filter(function (f) {
            var match = toByKey[f.key];
            if (!match || match.data_type !== f.data_type) return false;
            if (f.data_type === "reference" && f.reference_table !== match.reference_table) return false;
            return true;
          });
        }

        function render() {
          var fields = compatibleFields();
          container.innerHTML = "";
          if (fields.length === 0) {
            container.textContent = "No hay campos en común entre estos tipos.";
            return;
          }
          fields.forEach(function (f) {
            var wrapper = document.createElement("div");
            wrapper.className = "form-check";

            var input = document.createElement("input");
            input.type = "checkbox";
            input.className = "form-check-input";
            input.name = "project_type_association[shared_field_keys][]";
            input.value = f.key;
            input.id = "shared_field_key_" + f.key;
            input.checked = initiallyChecked.indexOf(f.key) !== -1;

            var label = document.createElement("label");
            label.className = "form-check-label";
            label.setAttribute("for", input.id);
            label.textContent = f.label + " (" + f.key + ")";

            wrapper.appendChild(input);
            wrapper.appendChild(label);
            container.appendChild(wrapper);
          });
        }

        fromSelect.addEventListener("change", render);
        toSelect.addEventListener("change", render);
        render();
      });
    </script>
```

Add to the `private` section (near `project_params`):

```ruby
  def prefill_shared_fields
    return if @associate_with_project_id.blank? || @project_type_association_id.blank?
    association = ProjectTypeAssociation.find_by(id: @project_type_association_id)
    source = Project.find_by(id: @associate_with_project_id)
    return if association.nil? || source.nil?

    source_fields = source.project_type.field_definitions.index_by(&:key)
    target_fields = @project_type.field_definitions.index_by(&:key)

    @project.custom_fields = association.shared_field_keys.each_with_object({}) do |key, fields|
      source_field = source_fields[key]
      target_field = target_fields[key]
      next unless source_field && target_field
      next unless source_field.data_type == target_field.data_type
      next if source_field.data_type == "reference" && source_field.reference_table != target_field.reference_table

      value = source.custom_fields[key]
      fields[key] = value if value.present?
    end
  end
```
